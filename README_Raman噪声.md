# 三脉冲 Raman 噪声与陀螺仪短期灵敏度

在 VS Code 的“运行和调试”中选择 **Rb87 10 - 三脉冲噪声与短期灵敏度**，或在项目根目录执行以下命令。程序读取同一份 256 原子仿真检查点，对每个工况保留其位置、速度、内态和探测口径。基线含探测噪声，四个单项依次叠加激光相位、镜面振动、纵向磁场和光强扰动，最后同时开启四项。

```powershell
python -m rb87_beam.raman_noise_study --output beam_outputs/raman_noise
```

快速试运行可追加 `--records 32 --scans 12`。正式比较默认抽取 4096 个独立技术噪声记录，并从这些记录中重采样生成 256 次含计数噪声的完整扫描，每扫 41 个相位点。每一个点对应独立探测门。技术扰动在同一门内由所有轨迹共用。相同的随机种子使每项在单独开启和同时开启时使用相同的扰动样本。

## 改变噪声幅度和相关性

复制 `beam_configs/raman_noise_budget.json`，调整下表字段后，将副本路径传给 `--noise-config`。某项 RMS 设为 0 即可关闭该项。`--config` 指定已有的原子束与 Raman 功率配置，`--source-state-h5` 指定已制备原子。下表幅度和相关性均为演示假设，实验复现时应替换为原子处或参考光路的标定值。

| 物理量 | 幅度字段和默认值 | 相邻两区相关系数 | 在传播中的作用 |
|---|---|---:|---|
| 双光子相对相位 | `phase_rms_rad = 0.05` rad | `phase_zone_correlation = 0.35` | 给第 j 个有限脉冲的耦合相位加上 δφⱼ |
| 参考镜位移 | `mirror_displacement_rms_m = 3e-9` m | `mirror_zone_correlation = 0.8` | 沿有效波矢的投影改变光学相位 −k_eff δxⱼ，其中 k_eff ≈ 4π/λ |
| 纵向磁场 | `field_rms_G = 0.005` G，`bias_field_G = 0.1` G | `field_zone_correlation = 0.5` | 扣除已补偿的偏置频移，钟跃迁扰动 δνⱼ = 575.15 [(B₀+δBⱼ)²−B₀²] Hz，场强以 G 表示 |
| 两色共模功率 | `fractional_power_rms = 0.02`，相对 RMS 为 2% | `log_power_zone_correlation = 0.65` | 两色强度同步乘同一正因子，平均因子为 1。保持光束面积与两色功率比，Ω_eff 与差分 AC 光移同步变化 |

相位、振动位移、磁场用零均值高斯分布。强度用对数正态分布，确保功率为正。每项三区的高斯变量相关系数为 ρ 的 |i−j| 次方，光强一项的 ρ 指对数功率。不同种类的扰动彼此独立，各区位移代表局部参考光路的相对运动。若三光区共用同一刚性光学参考，可以将镜位移相关系数设为 1，检查共同位移的抵消。将装置测得的宽带加速度谱换算为三次相互作用的位移协方差，需要另行使用该装置的光路和振动传递函数。

钟态为 ⁸⁷Rb 的 |1,0⟩ 和 |2,0⟩。对每个区实行有限脉宽幺正传播，磁场同时在两段暗区积累相位。每个暗区的前半、后半分别沿用相邻光区的场值，各原子使用自身纵速得到的实际暗时间。这里的偏置场沿量子化轴，横向转场、磁梯度力和磁子态跃迁均在模型范围之外。物理依据见 [Steck 的 ⁸⁷Rb 参数表](https://steck.us/alkalidata/rubidium87numbers.pdf) 和 [Cheinet 等的三脉冲相位响应](https://arxiv.org/abs/physics/0510197)。

## 读懂输出

| 文件或字段 | 含义 |
|---|---|
| `noise_budget.csv`、`noise_budget.png` | 六个工况的平均条纹对比度和 1 s Allan 偏差。图上误差棒是固定源样本条件下技术扰动抽样的一个标准误。 |
| `noise_fringes.csv`、`noise_fringes.png` | 每个相位的平均期望、计数抽样均值和单次扫描样例。图中下半部放大相对于探测基线的差值。 |
| `noise_budget.json` | 配置、输入路径、轨迹数、有限差分步长复核、逐工况光学传播插值和直接积分抽查误差。 |
| `accepted_flux_per_s`、`target_flux_per_s` | 几何及制备筛选后到达探测口的总通量，以及其中在 Raman 入口占据 F=1、mF=0 态的有效通量。两项均按每秒进入连续束的原子数计，对所有工况保持一致。 |
| `contrast`、`single_scan_contrast_q025/q50/q975` | 前者对各门的条纹系数取均值后计算 C = √(b² + c²)/a。后者分别是含真实计数抽样的单次相位扫描拟合对比度的 2.5%、50%、97.5% 分位数。 |
| `dP2_dOmega`、`sigma_rotation_gate_rad_s` | 固定工作点的探测布居斜率与单门角速度不确定度。 |
| `allan_1s_rad_s`、`arw_deg_per_sqrt_h` | 单束模型在独立记录假设下预报的 1 s Allan 偏差（rad/s）和角随机游走（°/√h）。 |

读出处在固定第三脉冲相位 4.71608 rad。对每个工况复算正、负角速度扰动，并在两侧共用相同技术噪声，取平均荧光信号对 Ωᵧ 的中心差分斜率 S。工作点的总方差为 E[Var(P₂ | 技术扰动)] + Var(E[P₂ | 技术扰动])。前项含泊松原子数及态分流、荧光与背景的光子散粒噪声、独立高斯电子学读数，使用高计数条件下归一化布居的一阶方差传播。后项来自每个记录整组原子的共同波动。单门角速度标准差为 σ(P₂)/|S|。

默认每门积分 10 ms，独立记录周期 20 ms。单个记录期间各光区的扰动保持准静态，两个记录之间留出足以覆盖最慢样本从第一脉冲飞至探测器的时间。采用门间独立假设后，输出由 σΩ(τ) = σΩ,门 √(T周期/τ) 计算。改变采样周期会同时改变探测基线和技术噪声的 1 s 折算。预测针对前向单束与给定有效通量，双束差分抑制、门内高频振动及长时相关漂移需要用对应的仪器时序和实测谱另行计算。

## 默认样例结果

按随附配置和种子 27887 计算。总接受通量为 1.0000×10¹⁰ 原子/s，制备并通过孔径的 F=1、mF=0 有效通量为 9.8114×10⁹ 原子/s。六个工况通过相同的孔径，探测门都包含平均 10⁸ 个原子。对比度表示 4096 个独立记录的平均条纹，表中 1 s Allan 偏差为固定工作点的单束仿真预报。

| 工况 | 平均条纹对比度 | 1 s 角速度 Allan 偏差（rad/s） |
|---|---:|---:|
| 仅探测 | 48.7916% | 1.9214×10⁻⁷ |
| 探测 + 双光子相位 | 48.5822% | 5.1201×10⁻⁵ |
| 探测 + 参考镜位移 | 48.7359% | 2.5414×10⁻⁵ |
| 探测 + 磁场 | 48.7914% | 1.1604×10⁻⁶ |
| 探测 + 光强 | 48.6889% | 2.7000×10⁻⁶ |
| 全部开启 | 48.4215% | 5.7580×10⁻⁵ |

四项同时开启时，平均条纹对比度的抽样标准误为 0.0110 个百分点，1 s Allan 偏差的抽样标准误为 6.34×10⁻⁷ rad/s。磁场单项对对比度的改变量小于其抽样标准误。所有误差均以这份固定的原子样本及配置为条件。
